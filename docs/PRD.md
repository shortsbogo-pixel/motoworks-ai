# 모토웍스 AI V1 제품 요구사항

## 목표

정비내역서 사진을 안전하게 수집하고, AI 판독 결과 중 불확실한 값만 사람이 검수한 뒤 정비·고객·차량·결제·렌트 정산에 반영하는 멀티지점 운영 SaaS를 만든다.

## 사용자와 권한

- 조직 관리자: 조직 전체 설정, 지점, 사용자, 엑셀 내보내기
- 지점 관리자: 배정 지점의 검수 승인, 정비 및 정산 관리
- 직원: 사진 업로드, 판독값 수정, 허용된 업무 처리
- 열람자: 승인 데이터와 리포트 조회

모든 서버 쿼리는 `organization_id`와 허용된 `shop_id` 범위를 강제한다. 개인정보 조회와 내보내기는 감사 로그에 남긴다.

## 핵심 흐름

1. 사진을 배치 단위로 업로드하고 원본 해시와 비공개 저장 키를 기록한다.
2. 비동기 작업이 회전, 원근, 명암 보정 후 JSON Schema 형식으로 필드를 추출한다.
3. 규칙 엔진이 날짜, 매장, 차종, 고객 연결, 금액, 중복을 검증한다.
4. 신뢰도 96% 미만 또는 충돌한 필드만 검수 화면에서 강조한다.
5. 승인 전 데이터는 매출, 고객 이력과 정산에 반영하지 않는다.
6. 승인 트랜잭션이 정비, 작업, 결제, 고객·차량 연결, 정산과 감사 이력을 함께 기록한다.

## 핵심 정책

- 매장은 확정, AI 추정, 미확인 상태를 분리한다.
- 날짜 원본, 정규화 후보, 신뢰도, 변경 사유와 최종 승인값을 각각 보존한다.
- 차종은 제조사, 모델, 배기량, 연식으로 분해한다. 별칭은 후보 추천에만 사용한다.
- 고객은 자동 병합하지 않는다. 후보, 일치 근거, 충돌, 승인과 해제 이력을 관리한다.
- 중복은 원본 해시, 배치, 지점, 차량번호, 작업 항목과 금액으로 후보화한다.
- 결제는 정비와 분리해 카드, 현금, 이체를 여러 건 저장한다.
- 렌트 정비는 기준가, 고객 결제, 업체 청구, 입금, 미수와 상태를 분리한다.

## 자동등록

필수 신뢰도 96% 이상, 작업 합계와 결제 합계 일치, 매장 확정, 고객 또는 차량 식별, 차량 충돌 없음, 중복 후보 없음, 개인 정비가 0원이 아님을 모두 만족할 때만 자동등록한다. 기준은 설정값으로 관리한다.

## 성공 지표

- 검수 항목당 평균 수정 시간
- 자동등록률과 승인 후 재수정률
- 중복 후보 적중률
- 원본과 추출 필드 연결 완전성
- 지점별 정산 마감 소요 시간
- 승인 데이터와 엑셀 내보내기 합계 일치율

## 범위와 현 상태

V1 UI, Mock 추출, 정책 엔진, D1/R2 구조, 5개 시트 내보내기와 검사가 구현되어 있다. 실제 AI 공급자 연결, 이미지 보정 워커, 운영용 큐, 개인정보 암호화 키 관리와 원본 211건/12장 검증은 실제 자료와 운영 자격 증명이 필요하다.
