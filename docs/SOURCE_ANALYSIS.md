- 요구사항 텍스트 1개

## 수신되지 않은 파일

- `4_build_excel.py`, `5_build_excel_lib.py`, `6_export_data_json.py`, `7_read_prev_excel.py`
- `정비내역서_2026-09-03_통합.xlsx`
- `KakaoTalk_20260904_152111642.jpg` 및 `_01`~`_11` 이미지
- `maintenancelog.html`, `정비내역서관리.html`

따라서 import 오류의 실제 호출부, 기존 5개 시트의 정확한 셀 배치와 서식, 211건·6,493,000원 합계, 신규 12장 필기는 재검증하지 못했다. 제공된 기준값은 화면에서 “참조 기준·검증 대기”로만 표시하고 확정 데이터로 적재하지 않는다.

## 호환 전략

- 새 코드의 Python 모듈 이름은 숫자 접두어 없이 `build_excel_lib`로 두고 진입점과 라이브러리를 패키지로 분리해야 한다.
- 기존 원본 파일은 읽기 전용으로 열고 결과는 항상 새 파일명으로 출력한다.
- 정확한 시트 이름과 열 매핑은 원본 수신 후 fixture로 고정하고 회귀 테스트에 추가한다.
- 예외는 `error_code`, `error_message`, 배치와 작업 상태에 기록하며 빈 `except`를 허용하지 않는다.
