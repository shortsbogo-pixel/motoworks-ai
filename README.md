# 모토웍스 AI

오토바이 정비소용 멀티지점 AI 접수·검수·정산 SaaS V1입니다. 원본 사진과 판독 필드를 연결하고, 불확실한 값은 검수함으로 보내며 승인된 데이터만 매출과 고객 이력에 반영합니다.

## 구현 범위

- 반응형 운영 대시보드와 모바일 사진 일괄 업로드
- Gemini 3.8 Flash 실판독 및 사진 최대 12장의 검수 대기 흐름
- 원본 위치와 판독값 비교, 필드별 신뢰도·원본값·수정값
- 승인·반려, 승인 데이터만 매출 반영
- 고객 병합 후보, 렌트 0원·청구·미수금, 분할 결제 UI
- 지점별 분석, 기준정보, 사용자·권한, 감사 이력
- D1 관계형 스키마와 R2 원본 저장 바인딩
- JSON Schema 기반 AI 응답 계약
- 5개 시트 엑셀 구조 검사와 승인 데이터 내보내기
- 자동등록·중복 지문·엑셀 회귀 테스트

## 로컬 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run db:generate
npm run dev
```

개발 서버가 표시한 Local URL을 엽니다. 기본값은 Mock 모드이며 API 키가 없어도 전체 화면을 사용할 수 있습니다.

## 검증

```bash
npm test
npm run typecheck
npm run lint
npm run build
```

## 환경변수

`.env.example`을 `.env.local`로 복사하고 실제 값은 로컬 비밀 저장소에서만 관리합니다. 실제 비밀키를 커밋하지 마세요.

## 원본 자료 연결

운영 사진은 화면에서 실제 작업센터를 먼저 선택해 업로드합니다. 원본은 R2에 비공개 저장하고 Gemini 판독값은 D1에 저장하며, 개인정보 필드는 `DATA_ENCRYPTION_KEY`로 암호화합니다. 승인 또는 반려 전에는 매출과 고객 이력에 반영하지 않습니다.
